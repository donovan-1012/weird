# 神秘点击页

一个充满问号与神秘小标题的静态互动网页，点击方块会发生奇怪的事。

## 功能列表

- 页面标题为「？？？？？？？？」的神秘主题
- 三个小标题：「？莫名其妙！」「📜 点击查看人生终极问题（大概）」「🎲 点击方块会发生奇怪的事」
- 点击方块触发随机奇怪效果
- 纯静态实现，无需构建，无外部依赖
- 包含 `.nojekyll`，适配 GitHub Pages 直接发布

## 如何本地打开

1. 下载或克隆本仓库到本地。
2. 直接用浏览器打开根目录下的 `index.html` 即可。
3. 也可以启动一个本地静态服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

## 发布到 GitHub Pages

将仓库推送到 GitHub，在仓库设置中开启 Pages，选择对应分支根目录即可，入口文件为 `index.html`。
